# Walter Liu — Personal Brand Website

A one-page personal brand website built with plain HTML/CSS (no build tools required).

## Structure
- `index.html` — main page (English)
- `css/style.css` — styles
- `assets/` — images (e.g. `profile.jpg`)

## Deploy (Cloudflare Pages)
1. Push this folder to a GitHub repo
2. Cloudflare Dashboard → Pages → Create Project → connect the repo
3. Build settings: Framework preset = **None**, Build command = *(empty)*, Output directory = `/` (or empty)
4. After deployment, browse `https://<project>.pages.dev`
